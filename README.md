# Velorian Bank — HTML/CSS/JS + PHP/MySQL

A premium banking web-application demonstration using a static frontend and a PHP/MySQL backend.

**Backend:** PHP 8.1+ / PDO / MySQL or MariaDB  
**Email:** Resend API  
**Frontend:** HTML, CSS, JavaScript

Start with `README-PHP-MYSQL.md` for setup instructions.

The external transfer feature is a simulation and does not connect to real bank payment rails.
